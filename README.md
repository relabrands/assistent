# assistent

Sistema CRM y Asistente personal integrado con Firebase y React.

## Tecnologías

- **React + Vite + TypeScript**
- **Firebase** (App, Auth, Firestore, Storage)
- **Tailwind CSS & shadcn/ui**
- **Lucide Icons**

## Instalación y Configuración

1. Instalar dependencias:
